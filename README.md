# مشروع تطبيق حصن المسلم

تطبيق **حصن المسلم** هو تطبيق ديني يومي يحتوي على أذكار الصباح والمساء، ورد بعد الصلاة، أذكار النوم والاستيقاظ، السبحة، ومتابعة ورد المصحف والماء اليومي.  

---

## المميزات

1. **الأذكار**  
   - أذكار الصباح والمساء كاملة.  
   - أذكار بعد الصلاة، أذكار النوم، وأذكار الاستيقاظ.  

2. **المهام اليومية (أورادي)**  
   - الصلوات الخمس مع إمكانية إضافة مهام شخصية.  
   - تتبع المهام المنجزة وغير المنجزة.  

3. **السبحة الرقمية**  
   - اختيار الذكر المراد تسبيحه.  
   - عد التسبيحات مع إمكانية إعادة التعيين.  

4. **ورد المصحف**  
   - تتبع عدد الصفحات المقروءة يوميًا.  
   - إمكانية فتح صفحة المصحف (حالياً تظهر كمكان فارغ للصور).  

5. **متابعة شرب الماء**  
   - عد عدد أكواب الماء اليومية.  

6. **واجهة جذابة**  
   - تصميم RTL متوافق مع اللغة العربية.  
   - تأثيرات بصرية للأزرار والعناصر.
